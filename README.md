# AWS S3 Static Website Hosting

A hands-on AWS cloud project documenting how to host a static website using Amazon Simple Storage Service (Amazon S3).

## 📌 Project Overview

This project demonstrates the process of configuring an S3 bucket, uploading website files, and setting up static website hosting through the AWS Management Console.

## 🎯 Objectives

- Understand Amazon S3 and static website hosting.
- Create and configure an S3 bucket.
- Upload website files to the bucket.
- Explore public access settings for website content.
- Document the implementation process.

## 🛠️ Technologies Used

- Amazon Web Services (AWS)
- Amazon S3
- AWS Management Console
- HTML and CSS website files

## ⚙️ Implementation

1. Open the AWS Management Console.
2. Navigate to Amazon S3.
3. Create a uniquely named S3 bucket.
4. Configure the required bucket settings.
5. Upload the website files.
6. Configure website hosting and access settings.
7. Open the website endpoint to test the deployment.

## 📄 Project Documentation

The detailed PDF documentation, including implementation steps and screenshots, is available in this repository.

## 🔐 Security Considerations

This project is intended for educational purposes. Public access can expose files to anyone on the internet. Use non-sensitive demo content, review access permissions carefully, and apply appropriate security controls before any production deployment.

## 📚 Key Learnings

- S3 bucket creation and configuration
- Uploading objects to S3
- Public access settings
- Static website hosting concepts
- Cloud project documentation
